# QR Code Generator

A QR code generator project built in two versions: a browser-based web app and a Node.js command-line application.

---

## 🚀 Live Demo
https://JustSomeGuy7070.github.io/qr-code-generator/web-app/

---

## ✨ Features
### Web App
- Generate QR codes instantly from user input
- Download generated QR image
- Responsive modern UI

### CLI Version
- Accept URL input through terminal
- Generate QR code image file
- Save entered URL to a text file

---

## 🛠️ Tech Stack
- HTML5
- CSS3
- JavaScript
- Node.js
- inquirer
- qr-image
- fs

---

## 🎮 How to Use

### Web App
1. Enter a URL
2. Click **Generate QR**
3. Download the generated QR code

### CLI Version
```bash
npm install
node npm start
```
or 

```bash
npm install
node npm run dev
```

Enter a URL when prompted and files will be generated automatically.
